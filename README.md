# lobby-maker

Bot Discord organizador de jogos

## Comandos
- `/criar-evento titulo data_hora [vagas]` — cria evento com embed e botões (Confirmado/Talvez/Desistir)
- `/sortear-times` — divide os membros do canal de voz atual em 2 times

## Setup
```bash
pip install -r requirements.txt
```

```bash
python bot.py
```
